Notifications par e-mail
Interrupteur général — désactivé, aucun e-mail n'est envoyé, quels que soient les réglages ci-dessous.
Les e-mails sont coupés : aucun message ne part, ni depuis l'admin, ni depuis les scénarios n8n qui lisent profiles.notif_prefs. Les réglages par type ci-dessous restent enregistrés et reprendront effet à la réactivation.
Les préférences d'e-mail sont recopiées dans profiles.notif_prefs côté Supabase : c'est cette copie que lisent les scénarios n8n avant d'envoyer un message. Sans elle, un réglage local n'aurait aucun effet sur les e-mails réellement expédiés.
